An object that represents an RGB color with alpha channel support, as the cell record stores it: red, green, blue and alpha, one byte each. Values are not from 0 to 1, but from 0 to 255. The interior colors of a cell use this type. [`niPackedColor`](https://mwse.github.io/MWSE/types/niPackedColor/) keeps its bytes in another order and is not interchangeable with it.
