### `setViewOptions`
<div class="search_terms" style="display: none">setviewoptions, viewoptions</div>

Sets the options of a view that a mod draws with a camera or a rendered texture. A view with options gets the parts that are named in the table, in addition to what a view of its kind draws without options (the full tier of the wgpu renderer of MGE XE). A part that is off in `mge.render` stays off in every view. A part that the table does not name stays off in this view.

The key is the object that names the view: a `niRenderedTexture` (the view that renders into that texture), or a `niCamera` other than the world camera (that camera into the back buffer). The world camera is refused, because it is the main view.

The options last until you change them, until you pass `nil`, or until the key's object is freed. A view that is idle keeps them.

The player's setting `views.full_tier_max` limits how many views of a frame get the options. With the Direct3D 9 renderer the call stores the options and draws nothing more.

This function exists when the MGE XE API version is 4 or higher (check `mge.camera.setViewOptions ~= nil`).

```lua
local accepted = mgeCameraConfig.setViewOptions(key, { distantLand = ..., distantStatics = ..., grass = ..., distantWater = ..., shaders = ..., glows = ... })
```

**Parameters**:

* `key` ([niRenderedTexture](../types/niRenderedTexture.md), [niCamera](../types/niCamera.md))
* `options` (table, nil)
	* `distantLand` (boolean): *Default*: `false`.
	* `distantStatics` (boolean): *Default*: `false`.
	* `grass` (boolean): *Default*: `false`.
	* `distantWater` (boolean): *Default*: `false`. MGE XE's water and its reflection for this view.
	* `shaders` (boolean): *Default*: `false`. The post-processing chain for this view.
	* `glows` (boolean): *Default*: `false`.

**Returns**:

* `accepted` (boolean): `false` if MGE XE refuses the key, for example the world camera.
